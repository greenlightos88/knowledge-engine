|---|---|---|---|---|---|---|---|
| DEC-001 | YYYY-MM-DD | creator / team / agent proposal |  |  |  |  | proposed / approved / deprecated |

## Rules

- Record architectural decisions that alter motive, causality, mythology, timeline, relationship, reveal order, theme, ending or production scope.
- Do not record every wording adjustment.
- Never delete a superseded decision; mark it deprecated and link the replacing decision.
- Distinguish creator-approved canon from agent proposals.
- Include downstream files so continuity updates are auditable.

## Update policy

1. Add a preference only when supported by repeated creator choices or explicit instruction.
2. Record contradictory evidence instead of forcing consistency.
3. Never infer a universal preference from one project-specific decision.
4. Creator correction immediately outranks the prior profile.
5. Taste memory guides proposal generation; it never creates Canon.
6. Material changes require a dated entry in the decision ledger.

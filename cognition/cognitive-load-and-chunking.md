# Cognitive Load and Chunking

## Purpose

Control how much new information the audience must process at once and ensure complexity is spent on intended story pleasure.

## Mechanism

Working memory is limited. Audiences manage complexity by grouping details into meaningful chunks: a faction, rule, relationship, objective, location or repeated pattern. Unstructured novelty consumes more capacity than familiar or causally linked information.

## Core rules

1. Introduce fewer independent variables at the same moment.
2. Connect new information to an existing objective, relationship or consequence.
3. Reuse stable labels for important concepts.
4. Do not demand precise recall for information that received only incidental exposure.
5. Geography, goals and immediate danger should remain legible during complex action.
6. Productive ambiguity concerns meaning; destructive confusion concerns basic comprehension.

## Load sources

- unfamiliar names and terminology;
- simultaneous character introductions;
- changing locations;
- unstated goals;
- contradictory world rules;
- dense exposition;
- action without spatial anchors;
- multiple timelines;
- similar character voices or appearances;
- rapid shifts in tone, allegiance or causality.

## Diagnostic procedure

For a scene or sequence, count:

- new named entities;
- new rules;
- new objectives;
- new relationships;
- location changes;
- unresolved questions carried in;
- additional questions introduced.

The count is not a fixed rejection threshold. It identifies where the audience is paying processing cost.

## Repair strategies

- stagger introductions;
- merge redundant functions;
- attach exposition to immediate choice;
- establish geography before acceleration;
- convert abstract rules into visible consequence;
- give related information one repeated organizing label;
- answer one question before introducing several more;
- remove distinctions that never affect action.

## Tradeoffs

- Simplification can reduce richness.
- Repetition can feel obvious.
- Delayed explanation can create temporary confusion.
- Excessive clarity can destroy mystery, dread or comic escalation.

## Dependencies

Influences comprehension, pacing, mystery, action clarity, emotional access and recall.

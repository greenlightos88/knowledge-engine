# Memory Encoding and Recall

## Purpose

Ensure information required for later emotion, comprehension or payoff is encoded strongly enough to remain available.

## Mechanism

Story information is more likely to persist when it is distinctive, emotionally charged, causally used, repeated through variation, connected to an existing model or actively recalled before payoff.

## Core rules

1. Narrative importance does not guarantee audience memory.
2. A setup becomes durable when it affects behaviour or consequence.
3. Repetition should change context, meaning, stakes or ownership.
4. Emotional peaks can strengthen nearby memory but can also eclipse quieter details.
5. Payoffs should reactivate the relevant memory before or during reinterpretation when the interval is long.
6. Character, image, sound, phrase and action can function as retrieval cues.

## Memory functions

- setup retention;
- relationship history;
- rule retention;
- character differentiation;
- motif accumulation;
- joke callbacks;
- mystery evidence;
- emotional contrast;
- world orientation.

## Diagnostic signs

- payoff depends on a forgotten detail;
- names or factions blur together;
- the audience remembers information but not why it matters;
- callbacks require explanatory dialogue;
- recurring motifs feel decorative rather than cumulative;
- continuity is technically correct but experientially unavailable.

## Repair strategies

- make the setup alter a choice;
- give the detail a distinctive sensory form;
- repeat it under changed stakes;
- attach it to a relationship or emotion;
- use a brief retrieval cue before payoff;
- shorten the distance between setup and use;
- eliminate low-value information competing for retention.

## Tradeoffs

- Strong reinforcement can make payoffs predictable.
- Repetition can reduce naturalism.
- Distinctive cues can feel conspicuous.
- Compression improves recall but may reduce world texture.

## Dependencies

Influences payoff, continuity experience, motifs, reveals, comedy callbacks and emotional accumulation.

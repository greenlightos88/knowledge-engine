# Human Cognition Engine

## Purpose

Model how audiences notice, process, predict, misunderstand, remember and emotionally tag story information.

This domain exists to improve practical decisions about scene construction, reveals, pacing, exposition, suspense, comedy, horror and recall.

## Operational chain

```text
stimulus
→ attention
→ selection
→ interpretation
→ prediction
→ emotional appraisal
→ memory encoding
→ later recall or revision
```

Failure anywhere in the chain can make a sound story decision ineffective on the page or screen.

## Core concepts

- attention and salience;
- cognitive load and chunking;
- prediction and expectation;
- uncertainty and curiosity;
- surprise and model revision;
- memory encoding and recall;
- information sequencing;
- pattern recognition;
- misdirection and fair inference;
- comprehension versus productive ambiguity.

## Diagnostic questions

1. What is the audience attending to at this moment?
2. What information can they actively hold?
3. What do they currently believe?
4. What do they predict will happen?
5. What uncertainty is active?
6. What new information modifies their model?
7. What emotional value tags the information for memory?
8. What must remain available for a later payoff?

## Decision rules

- Salience must match narrative importance unless deliberate misdirection governs the mismatch.
- Information that matters later needs either repetition, emotional tagging, causal use or distinctive form.
- Confusion is useful only when the audience understands what kind of question they are holding.
- Surprise without recoverable setup creates randomness rather than revelation.
- Exposition should arrive at the moment it changes prediction, choice or consequence.
- Cognitive load should be spent on the intended pleasure, not on avoidable naming, geography or rule confusion.

## Required use

Load cognition doctrine when a task involves:

- audience confusion;
- flat reveals;
- weak suspense;
- forgotten setups;
- exposition density;
- mystery fairness;
- joke timing;
- scene readability;
- information overload;
- unclear geography or causality.

## Anti-patterns

- assuming stated information was understood;
- presenting multiple equal-salience facts when only one matters;
- hiding essential causal information and calling it mystery;
- repeating information without changing its meaning;
- relying on audience memory without reinforcement;
- mistaking obscurity for complexity;
- explaining a reveal before the audience has experienced it.

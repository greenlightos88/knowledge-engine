# Interiority and Association

## Principle

Human thought is not a clean explanatory transcript. It moves through association, interruption, sensation, memory, rehearsal, avoidance, and contradiction.

Interiority should not repeat what the audience already sees. It should expose the private meaning of what is seen.

## Association

A present stimulus may connect to:

- a memory fragment;
- an anticipated consequence;
- a private comparison;
- an unfinished argument;
- a bodily fear;
- a learned ritual;
- an image the person cannot suppress.

The connection must arise from character history and current pressure, not from the author's need for a poetic line.

## Memory discipline

Memory is selective and unstable. Under pressure, people often remember fragments: a gesture, smell, phrase, wrong detail, or bodily sensation. Avoid perfectly summarized flashback thinking unless the form requires it.

A memory earns space when it changes interpretation, choice, or emotional temperature.

## Interior avoidance

Characters rarely name the deepest truth immediately. They bargain, redirect, intellectualize, minimize, rehearse, or fixate on a manageable detail.

Private thought may still lie.

## Common failures

- interior monologue translating visible action;
- fully coherent self-analysis during crisis;
- generic rhetorical questions;
- memories inserted only to deliver backstory;
- metaphor detached from character experience;
- emotional conclusions arriving before the character has earned them.

## Repair method

1. Identify the character's unacceptable truth.
2. Identify the safer thought they use instead.
3. Find the present stimulus that activates the conflict.
4. render one precise association or fragment.
5. return to action before explanation exhausts the meaning.

## Acceptance standard

Interiority must create a layer unavailable from external action alone while preserving some distance between what the character experiences and what they can admit.
